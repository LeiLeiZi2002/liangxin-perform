# 热线心理支持职业胜任力测评量规

## 一、用途与适用范围

本量规用于评价受测者在实时语音心理援助热线情境中的职业胜任力。评价对象是受测者在一次通话中实际表现出来的专业行为，以及通话结束后提交的工作记录。

本量规评价的是热线心理支持，不等同于完整的心理咨询或心理治疗。受测者在一次热线通话中的主要任务是建立可工作的联系，理解来电缘由和当下需要，提供情绪支持，形成适合热线情境的初步判断，协商可行行动，在必要时处理风险、边界和资源衔接，并完成专业记录。

量规适用于一般情绪困扰、关系与生活压力、适应困难、反复求助、服务边界、危机风险及其他适合热线处理的来电。自杀或自伤风险不是所有案例的固定主题。每通有效通话均启用S1a基础风险筛查；只有案例实际提供了相应线索和观察机会，才启用S1b完整风险研判及后续高危处置模块。

## 二、评价材料

### 主要材料

1. 受测者与虚拟来电者的完整通话录音。
2. 带有说话人、话轮顺序和时间信息的对话记录。
3. 受测者在通话结束后填写的工作记录。

### 测量辅助材料

1. 案例中本次实际开放和披露的事实。
2. 本次通话实际出现的评分机会。
3. 通话中的技术故障、重连和音频异常记录。
4. 来电者主动结束、系统中断等非受测者原因造成的材料缺失。

虚拟来电者的内部状态只用于确认某项观察机会是否出现，不直接作为受测者能力证据。来电者是否平静、是否信任受测者、是否接受建议，不直接决定得分。

### 各维度的主要证据来源

| 维度 | 对话内容 | 原始音频与时间信息 | 工作记录 | 案例机会与披露记录 |
|---|---|---|---|---|
| C1 尊重性沟通与关系维护 | 主要证据 | 辅助判断语气和抢话 | 通常不使用 | 确认是否出现关系紧张或修复机会 |
| C2 倾听与情绪理解 | 主要证据 | 辅助判断明显情绪线索 | 可用于查看受测者如何概括来电者体验 | 确认哪些情绪线索实际呈现 |
| C3 来电诉求澄清与工作焦点 | 主要证据 | 一般不单独使用 | 辅助核对受测者最终如何表述焦点 | 确认案例是否提供多重诉求或焦点变化 |
| C4 信息整合与专业判断 | 主要证据 | 仅用于补充语境 | 主要证据 | 确认哪些事实已向受测者开放，防止用未披露事实倒推漏评 |
| C5 支持性介入与协同行动 | 主要证据 | 辅助判断介入时机和交流状态 | 辅助核对行动状态 | 确认拒绝、困难或调整机会是否实际出现 |
| C6 语音沟通与通话进程管理 | 主要证据 | 主要证据 | 通常不使用 | 排除系统造成的停顿、中断和重连 |
| C7 服务边界与伦理责任 | 主要证据 | 通常不单独使用 | 主要证据 | 确认是否出现保密、边界或升级处置机会 |
| C8 通话结束与后续安排 | 主要证据 | 辅助判断结束节奏和突然中断 | 辅助核对后续事项 | 确认是受测者结束、来电者结束还是技术中断 |
| C9 工作记录的准确性与可追溯性 | 用于核对 | 用于必要的语境核对 | 主要评价材料 | 用于核对披露事实和行动状态 |

## 三、评分结构

### 核心维度

| 编号 | 维度 | 核心问题 |
|---|---|---|
| C1 | 尊重性沟通与关系维护 | 受测者以什么样的姿态对待来电者，并如何维持可以继续工作的联系？ |
| C2 | 倾听与情绪理解 | 受测者是否听懂来电者正在经历什么，并能准确、克制地表达这种理解？ |
| C3 | 来电诉求澄清与工作焦点 | 受测者是否弄清来电原因，并确定本次通话最需要处理什么？ |
| C4 | 信息整合与专业判断 | 受测者能否把已获得的信息组织成有依据、可修正的工作理解？ |
| C5 | 支持性介入与协同行动 | 受测者提供的支持是否适合当前处境，并与来电者共同形成可行行动？ |
| C6 | 语音沟通与通话进程管理 | 受测者能否利用语音媒介维持清楚、有节奏、有方向的通话？ |
| C7 | 服务边界与伦理责任 | 受测者是否在热线职责、伦理和自身能力范围内开展工作？ |
| C8 | 通话结束与后续安排 | 受测者能否负责任地完成通话收束，并明确通话后的安排？ |
| C9 | 工作记录的准确性与可追溯性 | 工作记录是否准确、克制，并能够追溯到原始通话证据？ |

### 情景专项模块

除S1a基础风险筛查外，专项模块不固定出现在每个案例中。其他模块只有在本次通话实际出现相应情景，且受测者获得了有效观察机会时才进行评分。

| 编号 | 专项模块 | 启用条件 |
|---|---|---|
| S1a | 基础风险筛查 | 所有通话默认启用，不以来电者是否主动表现风险线索为前提 |
| S1b | 完整风险研判 | 案例提供了足以观察风险评估层次和研判质量的材料 |
| S2 | 高危状态下的安全处置与协作 | 已披露的信息提示需要立即形成安全安排或升级处置 |
| S3 | 强烈情绪、长时沉默与表达失序处理 | 出现持续哭泣、明显失控、长时沉默或暂时无法有效交流 |
| S4 | 精神病性体验与现实检验困难处理 | 出现幻觉、妄想样体验、明显现实判断困难或严重思维紊乱 |
| S5 | 反复来电、依赖与边界压力处理 | 来电者反复求助、要求排他性联系或以关系压力突破服务边界 |
| S6 | 攻击、骚扰与非服务性来电处理 | 出现持续辱骂、性骚扰、恶意占线或明显偏离热线用途的行为 |
| S7 | 第三方来电处理 | 来电者为他人求助、报告风险或要求热线直接处理未在场者 |
| S8 | 未成年人或疑似受侵害来电处理 | 涉及未成年人、虐待、性侵害、家庭暴力或其他需要特殊保护的情形 |

## 四、评分方法

### 指标表现状态

评分前先对每项指标记录表现状态。

| 状态 | 含义 |
|---|---|
| 充分表现 | 在已经出现的机会中，行为清楚、适当，并能根据情境调整 |
| 部分表现 | 出现了相关行为，但不完整、不稳定，或者调整不够及时 |
| 有机会未表现 | 情景已经给出明确机会，受测者没有表现出所需行为 |
| 反向行为 | 行为与专业要求相反，例如盘问、说教、否定感受、越权承诺或忽略明确风险线索 |
| 无观察机会 | 本次通话没有出现能够观察该行为的情景，或者材料因技术原因无效 |

指标状态用于整理证据，不直接换算分数。维度等级应结合本维度全部有效证据作整体判断。

### 维度等级

| 等级 | 总体含义 |
|---|---|
| 0 | 出现明确的伤害性、严重失当或关键安全底线问题 |
| 1 | 关键行为基本缺失，表现零散、失焦或持续依赖不合适的做法 |
| 2 | 出现部分关键行为，能完成简单情境下的部分任务，但完整性、稳定性或适配性不足 |
| 3 | 关键行为基本完整，能够依据来电者和情境作出适当调整 |
| 4 | 在复杂、含糊或高压力情境中仍能保持稳定判断，灵活调整并处理困难变化 |

等级描述的是本次通话中观察到的行为完整程度，不表示是否达到某一岗位标准。等级与岗位要求的对应关系需经标准设定后另行确定。

等级4必须有相应的复杂观察机会。通话顺利、来电者配合，只能证明基础能力稳定，不能据此推断复杂情境下的进阶能力。

维度或模块无法形成有效等级时统一标记为“未评分”，不得按0分处理。未评分须注明原因：无观察机会、材料不足或技术中断。

### 必需行为与条件行为

每个维度的3级和4级锚点包含两类行为：

- **必需行为**：任何一次有效通话都应当出现，缺失即说明本次表现不完整。
- **条件行为**：只有案例提供了相应情景才可能出现，例如关系紧张与修复、拒绝后的介入调整、来电者配合完成的收束。

条件行为在本次通话中没有观察机会时，按以下规则定级：

1. 该维度仍可依据必需行为定到3级。
2. 不得定到4级，因为4级必须有复杂观察机会。
3. 报告须注明“本次未提供相应条件行为的观察机会”，并列入未观察部分。

条件行为有机会而未表现的，按“有机会未表现”记录，可以据此定到2级或更低。

### 证据充分性

一个核心维度通常需要两个相互独立的互动片段，或者一个明确的案例探针和相应回应，才适合形成稳定等级。重复表述同一件事不算多组独立证据。

下列情况可以依据一个完整片段作出判断：

- 出现足以触发非补偿性底线的关键事件。
- 案例只设置了一个明确、完整且可重复检验的困难情景。
- 来电者主动挂断或技术中断，使该片段成为唯一有效机会。
- C8依据通话收束阶段的完整片段定级。收束是一次通话中的唯一事件，不适用两个独立片段的要求。

证据不足时标记为“未评分”，原因记为“材料不足”，不得为了形成完整能力剖面而强行评分。等级4必须同时具有复杂观察机会和相应的稳定表现。

### 三种记录方式的关系

| 概念 | 层级 | 作用 |
|---|---|---|
| 反向行为 | 指标 | 记录单条与专业要求相反的行为，作为维度定级证据 |
| 0级 | 维度 | 表示该维度的整体表现出现明确伤害性、严重失当或关键安全问题 |
| 底线事件 | 报告 | 独立记录关键事件，不被其他维度的较高等级抵消 |

三者独立判定，可以同时出现，也可以单独出现：

- 出现反向行为时，该维度不得高于2级；反向行为反复出现或造成实际不利后果时定为1级或0级。
- 0级依据该维度全部证据判定，不要求同时触发底线事件。
- 底线事件只由下节列举的六类情形触发，与维度等级分开记录。触发底线事件时，相应维度通常也处于0至1级，但等级仍按该维度的全部证据判定。

### 非补偿性底线

以下表现不能依靠其他维度的高分抵消：

- 明显羞辱、歧视、威胁或强迫来电者。
- 明知存在紧迫危险却结束通话且没有任何安全安排。
- 虚假承诺绝对保密，或者伪造已经完成的外部处置。
- 鼓励自伤、他伤、违法或其他明显危险行为。
- 建立私人、排他性或利用性的关系。
- 在工作记录中编造关键事实、风险证据或已经执行的行动。

出现上述情况时，应生成单独的底线事件，不只体现在维度等级中。

## 五、核心维度量规

## C1 尊重性沟通与关系维护

### 测量内容

评价受测者能否在短时间、匿名、缺乏视觉信息的通话中，以尊重、平等、非评判的方式与来电者建立并维持可以继续工作的联系。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 尊重与非评判 | 不因来电者的经历、情绪、想法或选择而责备、羞辱、讽刺或进行道德评价 |
| 平等互动姿态 | 不把自己置于审问者、教师或裁决者位置，避免盘问、说教和单方面纠正 |
| 表达自主性 | 尊重来电者暂不回答、需要停顿或对理解作出纠正的权利，不以关系压力迫使披露 |
| 关系紧张识别 | 能发现明显的不满、警惕、退缩、误解或顺从性应付，而不只是继续既定流程 |
| 关系修复 | 在回应不合适或出现误解后，能够承认具体问题、调整方式并重新建立合作 |

### 不在本维度评价

- 情绪判断是否准确，归入C2。
- 来电焦点是否清楚，归入C3。
- 是否说明保密、职责和关系边界，归入C7。
- 来电者最终是否信任或喜欢受测者。

### 主要证据

受测者原话、回应顺序、来电者明确提出的纠正或拒绝、受测者后续是否调整。来电者内部的“信任值”不得作为评分证据。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 出现明显羞辱、指责、歧视、威胁、强迫披露或利用关系施压的行为。 |
| 1 | 能维持表面交流，但经常使用盘问、教育、纠正或单方面说服；对来电者的拒绝和不满缺少回应。 |
| 2 | 基本尊重，没有明显评判；一般交流可以继续，但互动较程序化，遇到警惕、误解或关系波动时调整有限。 |
| 3 | 持续保持尊重、平等和非评判；能够给予表达选择，并处理一般性的犹豫、拒绝和关系紧张。 |
| 4 | 面对明显敌意、羞耻、退缩、反复试探或关系破裂风险时，仍能保持稳定姿态；既不压迫也不过度迎合，并完成有效修复。 |

3级中的“处理一般性的犹豫、拒绝和关系紧张”为条件行为，需要案例提供相应机会；没有机会时依据其余必需行为定级。

## C2 倾听与情绪理解

### 测量内容

评价受测者能否理解来电者叙述中的事实、情绪及其处境意义，并以准确、试探和便于核对的方式表达这种理解。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 内容跟随 | 能跟随来电者正在表达的事情，不随意跳过、误置时间线或抓住次要细节代替主要内容 |
| 情绪识别 | 能识别明确或含蓄表达的主要情绪，不只复述事件，也不把所有痛苦笼统称为“焦虑”或“难受” |
| 处境性理解 | 能把情绪放回具体事件、关系、损失、威胁或两难中理解，避免脱离语境贴标签 |
| 核对与修正 | 使用试探性表达确认理解；来电者纠正时能够调整，而不是坚持自己的解释 |
| 矛盾体验容纳 | 能同时看见来电者并存的愿望、顾虑和情绪，不急于把复杂体验简化成单一原因 |

### 不在本维度评价

- 是否确定本次通话的工作目标，归入C3。
- 是否形成整体专业判断，归入C4。
- 是否采取稳定、建议或问题解决措施，归入C5。
- 来电者是否因回应而立即平静。

### 主要证据

受测者的复述、情绪反映、澄清和核对；来电者对理解作出的明确确认、补充或纠正只能作为辅助证据。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 否定、贬低或嘲讽来电者的感受；坚持明显错误的解释；用未经证据支持的标签代替倾听。 |
| 1 | 主要跟随事情表面经过，回应以泛泛安慰、重复原话或快速解释为主，持续遗漏重要情绪。 |
| 2 | 能识别主要事件和一种核心情绪，部分回应贴合处境；对含蓄、矛盾或变化中的体验理解不稳定。 |
| 3 | 能准确连接事件、情绪和处境意义，使用试探性语言核对，并依据来电者的纠正及时修正理解。 |
| 4 | 面对多重情绪、含糊表达、羞耻掩饰或叙述失序时，仍能把握体验的变化和矛盾，保持准确而不过度解释。 |

3级中的“依据来电者的纠正及时修正理解”为条件行为，需要来电者实际提出纠正或补充；没有机会时依据其余必需行为定级。

## C3 来电诉求澄清与工作焦点

### 测量内容

评价受测者能否弄清来电者为什么在此时打来，区分事情经过、当前困扰和实际求助，并与来电者确定本次热线最需要处理的重点。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 来电缘由澄清 | 了解促使来电者此时求助的直接原因和近期变化 |
| 当前需要辨别 | 区分来电者是在倾诉、寻求信息、需要情绪稳定、希望解决问题，还是面临安全困难 |
| 重点与优先次序 | 当多个问题同时出现时，能够辨别最紧迫、影响最大或本次最可处理的部分 |
| 共同确认焦点 | 通过总结或核对与来电者确认工作重点，而不是由受测者单方面规定话题 |
| 焦点调整 | 新的重要信息出现后能够重新排序，不因先前设定的计划忽略当前变化 |

### 不在本维度评价

- 对问题成因和机制的理解，归入C4。
- 针对焦点采取何种支持，归入C5。
- 通话时间和话轮节奏，归入C6。

### 主要证据

开场探索、阶段性概括、优先事项讨论、来电者对目标的确认或修正，以及后续通话是否围绕已确认重点展开。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 明显曲解来电目的，强行处理与来电者需要无关的问题；来电者纠正后仍不调整。 |
| 1 | 收集了若干事实，但缺少来电缘由和工作重点；问题随叙述漂移或表现为机械问询。 |
| 2 | 能识别表面来电原因和一个主要问题，但对实际求助、优先次序或共同确认处理不足。 |
| 3 | 能区分事件、困扰和求助需要，与来电者确定适合本次热线处理的重点，并在必要时重新聚焦。 |
| 4 | 面对多个竞争性问题、含糊诉求或不断变化的信息，能够协商出清楚、现实且符合热线定位的优先工作焦点。 |

## C4 信息整合与专业判断

### 测量内容

评价受测者能否根据已获得的事件、情绪、认知、行为、功能、应对和支持信息，形成有证据、保留不确定性并能够随新信息修正的工作理解。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 信息相关性 | 围绕当前问题了解必要信息，避免漫无目的收集背景或遗漏明显影响判断的方面 |
| 信息关联 | 能把诱发事件、主观体验、行为反应、生活功能、既有应对和现实支持联系起来 |
| 证据边界 | 区分来电者原话、可确认事实、专业推断和仍未知的信息 |
| 判断与优先次序 | 能说明当前最值得关注的问题及理由，判断强度与已有证据相称 |
| 假设修正 | 遇到矛盾、纠正或新事实后能够调整原有判断，不执着于单一解释 |

### 不在本维度评价

- 只是把本次通话主题说清，归入C3。
- 支持措施是否合适，归入C5。
- 工作记录文字是否规范，归入C9。

### 主要证据

对话中的探索和总结、受测者在工作记录中的问题理解与判断依据、案例实际披露事实。未向受测者披露的案例事实不能用来判定其漏评。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 作出明显缺乏依据的诊断或结论；编造事实；遗漏已经明确出现的紧迫问题并据此采取不当行动。 |
| 1 | 信息零散且缺少关联，主要重复单项事实；判断依赖直觉、标签或单一原因，未说明不确定性。 |
| 2 | 能概括主要事件、情绪和部分功能影响，形成基本可理解的判断；信息整合、证据边界或修正能力仍不完整。 |
| 3 | 能整合事件、体验、功能、应对和支持信息，清楚区分事实与推断，并根据新信息调整工作理解和优先事项。 |
| 4 | 面对信息不完整、相互矛盾或存在多种解释时，能够保留合理假设、比较证据并形成清楚、可修正且适合热线职责的判断。 |

3级中的“根据新信息调整工作理解和优先事项”为条件行为，需要通话中实际出现新事实、矛盾信息或来电者纠正；没有机会时依据其余必需行为定级。

## C5 支持性介入与协同行动

### 测量内容

评价受测者能否把前面的理解转化为与来电者当前状态、需求和现实条件相匹配的支持，并与来电者共同形成能够执行的下一步。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 介入匹配 | 支持方式与已经确认的问题、情绪强度、认知状态和热线阶段相符 |
| 既有应对与资源利用 | 了解并使用来电者已有的有效经验、个人能力和现实支持，不把来电者视为完全被动 |
| 建议时机与方式 | 在充分理解后提供建议、信息或方法，避免过早、过量和脱离处境的方案输出 |
| 共同选择 | 提供有限、清楚的选择，讨论顾虑、偏好和可行性，不替来电者做非必要决定 |
| 反馈与调整 | 询问支持是否合适；遭到拒绝、无效或实施困难时能够修正，而不是重复原建议 |
| 行动层次 | 区分眼下需要完成的事情和通话后的后续安排，行动具体且责任主体清楚 |

### 不在本维度评价

- 来电者是否最终接受或执行建议。
- 服务是否越过伦理和职责范围，归入C7。
- 高风险状态下的安全行动，另由S2评价。

### 主要证据

受测者提出支持的时机、内容和依据，双方对可行性的讨论，来电者明确提出的困难，以及受测者是否调整。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 提供明显危险、羞辱性或强迫性的建议；以个人价值观代替专业支持；推动与已知处境明显冲突的行动。 |
| 1 | 主要依靠泛泛安慰、说教或成串建议；支持与前面的理解联系较弱，也未确认可行性。 |
| 2 | 能提供至少一种基本适当的支持或行动，但对既有资源、选择、执行困难或反馈调整考虑不足。 |
| 3 | 支持与当前需要相匹配，能够利用来电者已有能力和资源，共同形成具体可行的行动，并依据反馈进行调整。 |
| 4 | 面对多重限制、拒绝、失败经验或意见冲突时，仍能保持合作，灵活组合支持方式并形成分层、现实的行动安排。 |

3级中的“依据反馈进行调整”为条件行为，需要来电者提出困难、拒绝或反馈介入无效；没有机会时依据其余必需行为定级。

## C6 语音沟通与通话进程管理

### 测量内容

评价受测者能否在缺乏视觉信息的条件下，以清楚、可跟随的语言和适当节奏组织通话，并处理语音交流中的停顿、重叠、听不清和阶段转换。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 口语可理解性 | 表达简明、指向清楚，避免过多术语、长篇解释和含糊指令 |
| 话轮与回应空间 | 能让来电者完成表达，控制一次提问或说明的负荷，避免持续抢话和连续堆叠问题 |
| 交流线索适配 | 能根据可靠识别的交流线索调整自己的语速和表达密度，包括来电者的停顿长度、迟疑、打断与重叠，以及其言语内容中表达的状态 |
| 沉默与交流中断处理 | 能区分普通停顿、思考、情绪停顿和技术中断，并以适当方式确认和恢复交流 |
| 通话结构 | 开场、探索、工作和收束阶段基本清楚；能够使用简短总结和过渡维持方向 |
| 时间使用 | 在有限通话时间内保持重点，既不仓促推进，也不让通话长期停留在重复内容中 |

### 不在本维度评价

- 声音是否悦耳、是否符合某种性别或播音审美。
- 单一停顿时长、语速数值或打断次数本身。
- 强烈情绪失控和长时无法交流的专项处理，归入S3。
- 最终结束质量，归入C8。

### 主要证据

只使用能够从原始音频中可靠识别的事件，例如重叠区间、静音时长和受测者自身语速变化。合成语音的韵律参数不作为来电者情绪线索的证据。其他证据包括说话人时间轴、对话内容和技术故障记录；ASR分段不得直接代替话轮判断。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 持续使用明显压迫、嘲讽或失控的声音表达，或者在已知听不清和无法跟随时仍强行推进，导致通话无法正常进行。 |
| 1 | 表达冗长或含糊，频繁抢话、堆叠问题或忽略交流中断；通话缺少基本结构，来电者难以参与。 |
| 2 | 语言基本清楚，能够完成普通话轮交换；偶有节奏、负荷或阶段组织问题，但未持续破坏通话。 |
| 3 | 能根据可靠识别的交流线索调整节奏，合理处理停顿、重叠和听不清，并以清楚的过渡和总结维持通话方向。 |
| 4 | 面对表达反复、交流线索复杂、偶发技术中断或多次阶段变化时，仍能迅速判断并恢复自然、稳定、有重点的通话过程。 |

3级中的“合理处理停顿、重叠和听不清”为条件行为，需要相应事件实际出现；没有机会时依据其余必需行为定级。

合成语音的韵律细节（呼吸、哭腔、音量起伏）在技术验证完成前不作为评分依据。技术验证确认哪些声学事件可以稳定获取后，再决定是否恢复相关表述。

## C7 服务边界与伦理责任

### 测量内容

评价受测者是否了解热线能够提供的服务、保密和安全责任，在自己的岗位及能力范围内工作，并以透明、尊重来电者权利的方式处理边界问题。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 角色与服务范围 | 对热线能够提供的支持和不能承担的任务保持准确理解，不把一次热线包装成诊断、治疗或长期照护 |
| 隐私与保密 | 在相关情景出现时准确说明保密、必要例外及信息使用目的，不作绝对保密承诺 |
| 专业关系边界 | 不建立私人、排他性、经济性或其他超出服务关系的联系，不用自我披露转移工作重点 |
| 知情参与与自主 | 对重要评估、资源联系和可能的升级处置说明目的，允许来电者表达顾虑并参与决定 |
| 胜任力与责任范围 | 识别自身和热线能力限制，需要时提出适当的专业资源、机构流程或进一步服务 |
| 信息与行动诚信 | 不夸大资源效果，不承诺无法完成的事项，不把拟采取行动表述为已经执行 |

### 不在本维度评价

- 日常互动是否尊重，归入C1。
- 资源方案是否实际可行，归入C5。
- 高风险情况下具体升级行动是否充分，归入S2。

### 主要证据

受测者对角色、保密、资源和处置目的的说明，边界请求出现后的回应，以及工作记录中对行动和限制的表述。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 作出绝对保密或无法兑现的承诺；建立私人或排他性关系；严重越权；未经必要判断泄露信息；伪造外部处置。 |
| 1 | 对服务范围、保密或关系边界理解含糊，出现过度承诺、替来电者决定或提供超出热线能力的安排。 |
| 2 | 基本保持在热线职责范围内，能说明部分限制；对知情参与、保密例外或复杂边界的处理不够完整。 |
| 3 | 能在相关时机清楚说明角色、保密、限制和资源用途，尊重来电者自主，并在需要时使用合适的服务路径。 |
| 4 | 面对自主、安全、隐私和机构责任相互冲突的复杂情境，能够作出透明、最小必要、证据充分且可解释的处理。 |

## C8 通话结束与后续安排

### 测量内容

评价受测者能否识别结束条件，向来电者清楚传达通话正在收束，回顾已经完成的工作，并确认通话后的行动和继续求助路径。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 结束时机 | 综合通话目标、来电者当前状态、未完成事项和时间条件判断是否适合结束 |
| 结束预告 | 以自然、明确的方式提示通话即将结束，避免突然中止 |
| 共同回顾 | 简要总结已经谈清的内容、仍未解决的问题和本次通话的实际进展 |
| 状态与行动确认 | 确认来电者当前是否能够结束通话，以及下一步由谁、何时、做什么 |
| 连续性安排 | 根据需要说明再次来电、其他服务、现实支持或紧急求助路径，不作无法兑现的复联承诺 |
| 主动结束应对 | 来电者准备挂断、拒绝继续或突然中止时，能够在现有时间内完成必要回应和记录 |

### 不在本维度评价

- 通话中段的时间和结构管理，归入C6。
- 高危来电能否结束以及结束前的安全条件，归入S2。
- 来电者挂断以后系统是否自动重拨。

### 主要证据

结束前后的完整话轮、双方确认的行动、来电者主动结束时受测者已有的处理，以及工作记录中的未完成事项。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 在已经明确的紧迫问题或重要未完成事项仍存在时突然结束，且没有说明、确认或必要安排。 |
| 1 | 主要因时间或受测者意愿结束；缺少结束预告、回顾、状态确认和后续安排。 |
| 2 | 能提示结束，并完成基本总结或下一步安排中的部分内容；结束仍较程序化或存在明显遗漏。 |
| 3 | 结束时机合理，能够共同回顾、确认当前状态和具体行动，说明适当的继续求助路径并自然结束。 |
| 4 | 面对来电者突然想挂断、对结束不满、行动尚未落实或多项遗留问题时，仍能分清必要事项，完成负责任且不过度拖延的收束。 |

3级中的“共同回顾、状态确认和行动确认”包含条件行为。来电者突然挂断或拒绝继续时，只评价受测者在实际可用时间内能够完成的必需事项；没有机会完成的部分不作负面证据。

## C9 工作记录的准确性与可追溯性

### 测量内容

评价受测者能否把通话中的关键材料、专业判断、已完成工作、未完成事项和后续计划写成准确、简洁、可核对的职业记录。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 事实准确 | 记录与实际对话相符，不遗漏或改写影响判断的关键信息 |
| 来源区分 | 区分来电者原话、客观通话事实、受测者判断和尚未核实的信息 |
| 判断可追溯 | 记录中的重要结论标注了对应的通话依据，读者能够据此回到原始材料核对；不以一句笼统概括代替说明 |
| 行动状态区分 | 清楚区分已经讨论、已经同意、已经完成、拟采取和未能完成的行动 |
| 缺失与限制 | 记录没有问到、没有得到回答、受技术或通话中断影响的材料及判断限制 |
| 专业表达 | 语言中性、具体、克制，避免污名化、文学化、推测性和模板化表述 |

### 不在本维度评价

- 专业判断本身是否充分，归入C4或相应专项模块。
- 书写字数和格式美观程度。
- 工作记录是否与系统预设答案逐字一致。

### 主要证据

工作记录全文与原始通话、披露事实、行动事件的逐项对照。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 未提交有效记录，或者编造关键事实、风险证据和已执行行动；记录存在严重误导性或污名化内容。 |
| 1 | 主要只有结论或模板化概述；存在明显事实错误，事实与推断、已做与拟做相互混淆。 |
| 2 | 基本记录来电问题和主要行动，整体与对话相符；证据依据、未知信息、行动状态或表达准确性仍有明显缺口。 |
| 3 | 记录准确、相关且可追溯，清楚区分事实、判断、未知信息及行动状态，并说明重要限制和后续事项。 |
| 4 | 面对复杂、矛盾或信息不完整的通话，仍能形成结构清楚、证据充分、不过度推断并可支持后续专业工作的记录。 |

## 六、情景专项模块量规

## S1a 基础风险筛查

### 启用与测量内容

所有通话默认启用。依据国家卫生健康委《心理援助热线技术指南（试行）》对每次接听均应评估来电者当下自杀危险的要求，本模块不以来电者是否主动表现风险线索为启用前提。

评价受测者是否在本次通话中以适当方式触及来电者当下的安全风险。本模块只评价筛查动作本身，不要求完成完整评估流程；完整评估的层次与质量归S1b。

唯一免评情形是来电者在受测者获得任何筛查机会前主动结束通话，或者技术中断导致材料无效。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 筛查覆盖 | 在通话中触及死亡、自杀或自伤想法，不因来电者未主动提及而完全跳过 |
| 提问方式 | 使用直接、平静、可回答的措辞，不以委婉暗示、诱导性否定或道德化表达代替提问 |
| 时机适当 | 在建立基本联系之后、通话结束之前完成；不在开场机械插入，也不拖到收束时敷衍带过 |
| 回应跟进 | 对来电者的回答作出回应；出现肯定或含糊回答时进入进一步了解，不停留在一次问答 |
| 否认结果处理 | 来电者否认时如实记录否认本身，不把一次否认等同于本次通话无风险 |

### 不在本模块评价

- 完整风险评估的层次、覆盖面与研判质量，归S1b。
- 风险确认后的安全安排与升级处置，归S2。
- 提问时的关系姿态与非评判性，归C1。
- 工作记录中风险内容的书写质量，归C9。

### 主要证据

受测者提出筛查问题的原话及其所在话轮位置、来电者的回答、受测者的后续跟进，以及工作记录中对风险方向的记载。案例是否声明风险事实不影响本模块启用。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 以道德、法律或羞耻方式阻止来电者谈及自杀想法；或在来电者主动提及后予以否定、嘲讽或转移话题。 |
| 1 | 整通通话未触及风险方向；或仅以“你不会做傻事吧”这类诱导否定的方式带过，且对来电者的回答未作任何回应。 |
| 2 | 触及了风险方向，但表达委婉含糊、时机明显不当，或对来电者的回答未作跟进。 |
| 3 | 在适当时机以直接、平静的方式询问，对回答作出回应；来电者否认时如实记录，不据此断定本次通话无风险。 |
| 4 | 面对回避、羞耻、含糊或明显话题阻力时，仍能自然完成询问并维持关系，并据回答判断是否需要进入完整研判。 |

## S1b 完整风险研判

### 启用与测量内容

只有案例提供了足以观察风险评估层次和研判质量的材料时启用。基础筛查归S1a；本模块评价受测者能否识别和澄清风险信息，并依据已经获得的证据判断风险的性质、动态变化和紧迫程度。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 线索识别 | 识别直接、间接和情境性风险线索 |
| 直接询问 | 直接询问死亡、自杀或自伤想法，不用委婉暗示代替关键问题 |
| 紧迫性信息 | 根据回答了解意图、计划、方法可及性、时间、既往行为和近期变化 |
| 风险与保护因素 | 了解绝望、冲动、物质使用、独处、现实支持及保护因素 |
| 综合研判 | 综合正反证据判断紧迫程度，不把主动来电、否认计划或存在保护因素等同于安全 |
| 限制说明 | 在专业判断中保留未获得的信息和判断限制 |

### 不在本模块评价

- 是否完成基础筛查，归S1a。
- 风险确认后的现实安全行动与升级处置，归S2。
- 风险提问中的尊重和非评判姿态，归C1。
- 工作记录是否准确标注证据和限制，归C9；本模块只评价研判本身是否有依据。

### 主要证据

来电者实际披露的风险信息、受测者的追问与澄清、前后判断变化，以及工作记录中的风险结论。案例尚未披露的风险事实不得用于判定受测者漏评。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 已出现明确风险线索却否定、嘲讽、鼓励危险行为，或用道德、法律和羞耻方式阻止披露。 |
| 1 | 对风险线索明显回避，或者只作含糊询问便得出安全结论，信息不足以支持判断。 |
| 2 | 能直接询问风险并覆盖部分紧迫性信息，但计划、可及性、时间、既往行为、支持或动态变化存在重要缺口。 |
| 3 | 能直接、平静并有层次地完成风险评估，综合风险与保护信息，判断与实际披露证据相符。 |
| 4 | 面对否认、矛盾、羞耻、反复改变说法或信息不完整时，仍能保持关系，澄清动态风险并清楚说明判断边界。 |

## S2 高危状态下的安全处置与协作

### 启用与测量内容

只有已披露信息提示需要立即形成安全安排、现实支持或升级处置时启用。评价受测者能否把风险判断转化为眼下可执行、能够核对且符合热线职责的安全行动。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 持续连接 | 在必要时保持连接，避免来电者在高危状态下独自中断 |
| 现实安全条件 | 确认当前位置、独处情况和能够及时到场的现实支持 |
| 危险可及性降低 | 与来电者协商降低危险手段可及性或远离危险环境 |
| 透明协作 | 说明收集信息和升级处置的目的，处理来电者对失去控制、保密和求助后果的担忧 |
| 升级与交接 | 根据紧迫性使用热线所属机构规定的督导、紧急服务或其他升级路径 |
| 行动核实 | 确认行动是否真正同意、开始或完成，不用空泛“保证不会做”代替安全安排 |

### 不在本模块评价

- 风险线索识别、信息覆盖和风险等级研判，归S1b。
- 普通情境中的支持性行动，归C5。
- 保密、自主和岗位范围的一般伦理判断，归C7；本模块只评价高危状态下如何落实安全行动。
- 交接、行动和未完成事项在工作记录中的书写质量，归C9。

### 主要证据

风险信息已经披露后的完整互动片段、受测者提出的安全行动、来电者对行动的明确回应、系统记录的行动状态和工作记录。工作记录中写“拟采取”不能证明通话中已经执行。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 已知存在紧迫危险却直接结束通话，鼓励危险行为，或者伪造已经启动的紧急处置。 |
| 1 | 只作一般安慰、劝阻或要求安全承诺，没有形成与紧迫程度相称的现实行动。 |
| 2 | 提出部分安全措施或资源，但对位置、独处、支持到场、可及性、行动确认或升级路径处理不完整。 |
| 3 | 能保持连接并与来电者落实匹配的安全行动，确认现实支持和必要升级，行动状态清楚可核对。 |
| 4 | 面对拒绝、位置隐瞒、支持失联、临时变化或多重阻碍时，能够持续更新判断，协商替代方案并完成稳妥交接。 |

## S3 强烈情绪、长时沉默与表达失序处理

### 启用与测量内容

来电者出现持续哭泣、明显情绪失控、长时沉默、反复中断或暂时无法形成连贯表达时启用。普通思考停顿不启动本模块。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 状态辨别 | 判断当前是情绪停顿、思考、拒绝、交流能力下降还是技术中断 |
| 负荷降低 | 降低语言和问题负荷，使用简短、可回应的表达维持联系 |
| 沉默容纳 | 允许必要沉默，不因受测者自身焦虑连续填满空间 |
| 稳定支持 | 根据来电者状态使用适当的稳定方法，并说明正在做什么 |
| 恢复工作 | 状态稍有恢复后重新确认当前需要和通话方向，不急于追补全部背景 |
| 安全留意 | 判断强烈失控是否伴随需要启用S1b或S2的风险信息 |

### 不在本模块评价

- 普通思考停顿、一般话轮和常规节奏调整，归C6。
- 来电者情绪及处境是否被准确理解，归C2。
- 基础风险筛查、完整风险研判和高危安全处置，分别归S1a、S1b和S2。

### 主要证据

出现强烈情绪、长时沉默或表达失序前后的完整音频和对话片段、可靠的静音及重叠事件、受测者的调整过程和技术故障记录。Actor内部情绪值只用于确认机会，不作为处理有效的证据。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 责备、嘲讽或催促来电者停止哭泣；在明显无法交流时持续逼问或直接抛下来电者。 |
| 1 | 主要依靠“别哭了”“冷静一点”等空泛要求，或者持续讲话填满沉默，未根据交流能力作出调整。 |
| 2 | 能放慢速度并尝试保持联系或稳定，但对状态判断、问题负荷、恢复时机或安全留意处理不完整。 |
| 3 | 能准确判断交流状态，控制语言负荷，容纳沉默并提供适当稳定支持，在恢复后自然重新建立工作方向。 |
| 4 | 面对反复失控、表达断裂、沉默与短暂恢复交替出现时，仍能保持稳定联系，灵活调整并同时留意安全变化。 |

## S4 精神病性体验与现实检验困难处理

### 启用与测量内容

来电者出现幻觉、妄想样体验、明显现实判断困难或严重思维紊乱时启用。评价重点是受测者如何理解这些体验对当下生活和安全的影响，而不是能否作出诊断。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 体验回应 | 不嘲讽、不争辩，也不直接确认明显不可靠的信念为事实 |
| 影响评估 | 了解体验对恐惧、行为、睡眠、功能和安全的影响 |
| 沟通适配 | 使用简单、具体、可跟随的语言维持交流 |
| 服务判断 | 区分能够继续热线交流、需要现实支持和需要医疗或紧急服务的情况 |
| 信息与转介 | 在提供信息或转介时避免污名化，并确认来电者能够理解和执行 |

### 不在本模块评价

- 是否作出精神障碍诊断，本测评不评价也不要求。
- 一般关系姿态和情绪理解，分别归C1和C2。
- 同时出现的自伤、他伤或即时危险，另行启用S1b和S2。
- 工作记录中的用语和证据标注，归C9。

### 主要证据

来电者实际表达的异常体验及其影响、受测者的回应和探索、资源说明与行动讨论。案例内部诊断或未披露事实不能替代通话证据。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 嘲讽、激烈争辩、故意强化危险信念，或者在明显安全风险下完全忽略。 |
| 1 | 只围绕体验真假争论，或者仓促贴上诊断标签，未了解生活影响和当前安全。 |
| 2 | 能保持基本尊重并了解部分影响，提出一般性专业求助建议；交流适配和安全判断仍不完整。 |
| 3 | 能在不争辩也不附和的情况下了解体验、功能和安全，使用清楚语言并提出适当支持或服务路径。 |
| 4 | 面对高度确信、思维跳跃、警惕或拒绝就医时，仍能保持联系，围绕可共同确认的现实需要形成可行安排。 |

## S5 反复来电、依赖与边界压力处理

### 启用与测量内容

来电者反复致电、要求固定咨询员、要求私人联系、以关系威胁换取服务或反复讨论相同问题时启用。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 模式识别 | 识别反复来电背后的情绪、功能和现实需要，不把来电者简单视为“麻烦” |
| 边界说明 | 保持尊重，同时清楚说明热线服务和关系边界 |
| 依赖控制 | 避免用特殊承诺、私人联系或无限延长通话缓解眼前压力 |
| 连续性回顾 | 回顾既往讨论和已尝试行动，避免每次从头重复或机械驱赶 |
| 替代安排 | 与来电者形成可持续的热线使用方式、其他支持或长期服务安排 |
| 关系压力处理 | 面对愤怒、失望和被抛弃感时能够维护关系而不取消必要边界 |

### 不在本模块评价

- 普通通话中的角色、保密和关系边界，归C7。
- 一般关系紧张和修复，归C1。
- 替代支持本身是否适合且可行，归C5；本模块评价其是否用于减少依赖和维持连续性。
- 工作记录是否准确，归C9。

### 主要证据

案例提供的既往来电摘要、本次边界请求、受测者对既往工作的回顾、边界说明和替代安排，以及来电者施加关系压力后的完整互动。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 羞辱、驱赶或报复来电者；建立私人、排他性联系；利用来电者依赖满足个人需要。 |
| 1 | 只重复规定或直接拒绝，未理解边界请求的功能；或者因害怕冲突作出无法维持的特殊承诺。 |
| 2 | 能说明基本边界并保持礼貌，但对反复求助模式、关系反应和替代支持处理不足。 |
| 3 | 能同时回应关系需要和设定边界，回顾既往工作，并共同形成更可持续的求助和支持安排。 |
| 4 | 面对反复试探、愤怒、威胁挂断或多次边界冲突时，仍能保持一致、尊重和连续性，不强化依赖也不粗暴中断关系。 |

## S6 攻击、骚扰与非服务性来电处理

### 启用与测量内容

来电者持续辱骂、威胁咨询员、进行性骚扰、恶意占线，或在说明后仍明显偏离热线服务用途时启用。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 行为辨别 | 区分痛苦状态下的激烈表达与持续针对咨询员的攻击或骚扰 |
| 稳定回应 | 保持冷静、简短和清楚，不以羞辱、争吵或报复回应 |
| 最低互动条件 | 说明热线可以继续提供服务的最低互动条件 |
| 调整机会 | 在适当时给予一次清楚的调整机会，并说明继续行为的后果 |
| 结束与记录 | 根据机构规则结束不适合继续的通话，并记录行为和处理过程 |

攻击性来电中同时出现真实风险线索时，S1a或S1b与S6同时启用并分别评分。S6只评价对攻击或骚扰行为的处理，风险识别与研判归S1a和S1b，高危安全行动归S2。

### 不在本模块评价

- 普通的不满、质疑和关系紧张，归C1。
- 自杀、自伤、他伤和其他安全风险，归S1a、S1b或S2。
- 一般服务边界和伦理责任，归C7；本模块只评价攻击、骚扰或非服务性行为下的设限。
- 工作记录的准确性和表达质量，归C9。

### 主要证据

攻击、骚扰或非服务性行为发生前后的完整对话、受测者的设限原话、是否提供调整机会、继续或结束通话的条件，以及工作记录中的事件描述。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 与来电者对骂、羞辱、威胁或进行报复性披露；因受到冒犯而忽略明确的紧急风险。 |
| 1 | 在愤怒中失去稳定，边界含糊或反复争论；突然挂断且没有必要说明。 |
| 2 | 能保持基本冷静并说明限制，但对行为性质、调整机会、结束条件或风险线索处理不完整。 |
| 3 | 能区分痛苦表达和骚扰行为，清楚设限、提供调整机会，并按规则结束或恢复服务。 |
| 4 | 面对攻击、操纵和真实求助线索交织的复杂来电，仍能保持安全、边界和必要支持之间的准确平衡。 |

## S7 第三方来电处理

### 启用与测量内容

来电者为家人、朋友、同事或其他人求助，要求评估未在场者、获取其信息或让热线直接采取行动时启用。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 身份与目的 | 澄清来电者与当事人的关系、来电目的和目前掌握的信息 |
| 证据边界 | 不把第三方描述直接当作对未在场者的诊断或完整评估 |
| 安全辨别 | 了解是否存在需要立即处理的人身安全问题 |
| 可行动焦点 | 把工作重点放在来电者能够采取的支持、沟通和求助行动上 |
| 信息边界 | 准确说明信息、隐私和热线行动范围，不泄露其他服务对象信息 |
| 求助路径 | 必要时说明如何鼓励当事人本人求助或使用现实紧急资源 |

### 不在本模块评价

- 对未在场者作完整心理评估，本模块明确不支持这类推断。
- 来电者本人的一般关系和情绪支持，分别归C1、C2和C5。
- 已确认紧急危险后的安全处置，归S2。
- 隐私和服务范围的一般伦理质量，归C7；本模块只评价第三方情境中的特殊边界。

### 主要证据

第三方关于身份、关系和事件的陈述，受测者对信息来源和限制的澄清，对当前安全的询问，以及围绕来电者可采取行动所形成的讨论。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 对未在场者作出武断诊断，泄露受保护信息，或者在明确紧急危险下提供明显错误的处理方向。 |
| 1 | 完全接受第三方单一叙述并替其作决定，或只要求“让本人打来”而没有处理当前可做事项。 |
| 2 | 能澄清基本关系和目的，提供一般支持；对证据限制、安全、隐私或行动范围处理不够完整。 |
| 3 | 能区分第三方信息和当事人评估，处理必要安全问题，并帮助来电者形成适当、现实的支持行动。 |
| 4 | 面对关系冲突、信息矛盾、当事人拒绝求助或安全责任不清时，仍能谨慎判断证据边界并形成可执行方案。 |

## S8 未成年人或疑似受侵害来电处理

### 启用与测量内容

来电涉及未成年人、疑似虐待、性侵害、家庭暴力或其他需要特殊保护的情形时启用。具体报告和升级责任必须结合测评所模拟机构的工作制度及适用法律配置，不能由通用模型自行推定。

### 行为指标

| 指标 | 观察内容 |
|---|---|
| 发展适配 | 使用与年龄、理解能力和当前情绪相适合的语言 |
| 必要事实 | 在不诱导、不审讯的前提下了解必要的安全事实 |
| 当前安全 | 识别当下是否仍与可能的伤害者共同生活或处于即时危险 |
| 保密与保护说明 | 说明保密边界、必要信息使用和可能的保护行动，避免无法兑现的承诺 |
| 角色与责任 | 区分来电者意愿、监护人角色和机构保护责任 |
| 保护资源 | 按模拟机构配置的程序讨论现实支持、医疗、保护或紧急资源 |

### 不在本模块评价

- 一般的保密、知情参与和服务范围，归C7；本模块评价特殊保护情境中的具体处理。
- 已确认即时危险后的高危安全行动，归S2。
- 工作记录是否准确区分事实、判断和行动，归C9。
- 机构未配置的法律和报告程序不得由评分模型自行补充后用于扣分。

### 主要证据

来电者实际披露的年龄、受侵害和当前安全信息，受测者的询问方式、保密与保护说明、现实行动讨论，以及案例为模拟机构配置的具体工作程序。

### 等级锚点

| 等级 | 行为表现 |
|---|---|
| 0 | 指责、怀疑或诱导来电者改变陈述；承诺绝对保密；把来电者重新推向已知危险且没有保护安排。 |
| 1 | 只作一般安慰或仓促追问细节，对年龄适配、安全、保密边界和保护责任缺少处理。 |
| 2 | 能保持基本尊重并了解部分安全信息，提出一般求助方向；对证据边界和机构程序掌握不完整。 |
| 3 | 能以适龄方式了解必要事实，透明说明边界，判断当前安全并按机构程序形成保护和支持安排。 |
| 4 | 面对来电者害怕后果、拒绝披露身份、家庭成员角色冲突或信息不完整时，仍能控制询问范围并形成最小必要、可解释的保护方案。 |

## 七、质性证据编码流程

本量规采用演绎与归纳相结合的编码方式。九个核心维度和情景专项模块提供预先确定的职业能力框架；第一轮编码仍应贴近原始材料，并允许记录量规尚未覆盖的新行为。不能为了填满量规而把所有对话片段强行归入预设指标。

### 1. 材料有效性检查

先核对录音、转写、说话人和工作记录是否完整，标记技术中断、错误转写和无法归因的音频事件。技术故障不得作为职业能力不足的证据。

### 2. 划分意义单元

编码单元采用“意义单元”或“互动片段”，不按照标点、ASR切句或固定话轮数量拆分。一个互动片段可以包括来电者线索、受测者回应及紧接着的来电者反馈。

### 3. 初始编码

保留原始中文表达，先用贴近材料的短语描述受测者做了什么。例如：

> “在来电者纠正后继续坚持原来的解释”

此阶段不直接写成“共情能力差”之类的总结性结论。

### 4. 聚焦编码与量规映射

将初始编码映射到相应指标，并记录：

- 所属维度和指标。
- 表现方向：支持、限制或反向。
- 观察机会是否真实出现。
- 证据强度和上下文。
- 是否存在其他合理解释。

### 5. 反例检查

形成维度结论前，主动寻找与初步判断相反的材料。例如，已经发现一次盘问式提问，还要检查受测者后续是否意识到问题并完成修复。不能只挑支持预设结论的片段。

### 6. 整体定级

依据本维度全部有效证据、出现阶段、重复程度、情境难度和后续修正进行整体定级。不得使用关键词计数、指标简单平均或单句命中直接生成等级。

### 7. 形成报告证据链

每个维度的报告至少包括：

1. 等级及对应能力描述。
2. 主要表现模式，不只是一句概括。
3. 两组左右的代表性证据；材料不足时明确说明。
4. 对表现形成限制的证据或反例。
5. 本次案例提供了哪些观察机会，哪些能力没有机会判断。
6. 结论置信程度及其来源。

如果一次关键事件已经足以构成严重伦理或安全问题，可以使用单一事件作结论依据，但必须保留完整上下文并说明其关键性。

## 八、评分模型的证据边界

### 可以判断

- 受测者实际说了什么、在什么上下文说、随后是否调整。
- 问题、反映、总结、建议和行动之间是否有逻辑联系。
- 工作记录是否与通话和实际披露内容一致。
- 案例已提供的观察机会中，受测者是否表现出相应能力。
- 原始音频中能够可靠识别的语速变化、重叠、长时静音和技术中断。

### 不能直接判断

- 受测者内心是否真诚、是否真正关心来电者。
- 来电者是否真的产生信任或长期获益。
- 一次模拟通话能否代表受测者在所有真实工作中的稳定水平。
- 单凭语音风格推断人格、态度或专业动机。
- 根据未披露的案例真相反推受测者“应该知道”。

### 依赖情景设计后才能判断

以下能力分两类：一类是维度内的条件行为，只影响该维度3级要素能否被观察到；另一类是整个专项模块的启用条件。两者都必须由案例预先设置观察机会。

维度内的条件行为：

- 关系破裂与修复（C1）。
- 来电者纠正后的理解修正（C2）。
- 新信息出现后的判断调整（C4）。
- 面对拒绝或反馈无效后的介入调整（C5）。
- 停顿、重叠与听不清的处理（C6）。
- 来电者配合完成的收束（C8）。

专项模块的启用条件：

- 复杂情绪和长时沉默处理（S3）。
- 高危安全协作（S1b、S2）。
- 边界压力、反复来电和骚扰处理（S5、S6）。

这些能力必须由案例预先设置明确而自然的观察机会。Actor可以自由生成具体措辞，但不能随意省略测量所需的关键情景，也不能因为受测者表现一般就自动配合或改善。

### 案例评分机会的运行约束

除S1a外，维度和专项模块的启用必须依据案例预先声明的评分机会，不能由评分模型只根据最终对话临时推断。否则可能出现“受测者没有询问—来电者没有披露—模块没有启用—遗漏反而免评”的错误链条。

案例评分机会应满足以下要求：

1. **允许一对多**：同一维度可以设置多个相互独立的评分机会，用于观察表现是否稳定。
2. **允许缺席**：案例没有提供某个条件能力或专项模块的机会时，该部分可以不启用。
3. **区分必需与条件**：必需行为用于评价任何有效通话中的基础表现；条件行为只有相应情景实际出现后才评价。
4. **记录实际兑现情况**：通话结束后核对案例声明的评分机会是否真正出现在来电者的实际表达中。

案例已经声明但实际对话没有呈现的机会，标记为“机会未兑现”。受测者不因该机会未兑现而失分，报告应将其列入未观察部分。S1a不适用上述启用逻辑；除来电者在任何合理筛查机会前挂断或发生技术中断外，所有通话都默认提供基础筛查机会。

## 九、结果呈现

测评结果以九个核心维度的能力剖面、实际启用的专项模块、底线事件和证据覆盖情况为主，不以未经验证的总分替代专业判断。

### 本结果不支持的判断

本量规当前处于开发阶段，尚未完成标准设定与效度验证。结果不得用于：

- 判定受测者是否胜任热线岗位，或者是否达到某一执业水平。
- 录用、考核、晋级、资格认定或其他具有后果的人事决定。
- 与他人比较排名，或者跨案例、跨场域比较等级高低。
- 推断受测者在真实工作中的稳定表现。一次模拟通话不足以支持这类推断。

当前结果只用于发展性反馈：说明本次通话中观察到了什么、缺少什么，以及下一步可以练习什么。

### 结果摘要

报告开头给出结构化摘要，只陈述本次测评事实，不给出通过与否或等级归类结论。摘要包括：

1. 本次形成等级的核心维度数量，以及未评分维度及其原因，包括无观察机会、材料不足或技术中断。
2. 实际启用的专项模块，以及其他专项模块未启用的原因。
3. 是否出现底线事件。底线事件判定的是所列关键行为是否发生，可以作为事实直接呈现。
4. 等级分布的描述，例如“九个核心维度中六个形成等级，其中四个为3级、两个为2级，三个因无观察机会未评分”。不计算平均值，不排序，不合成指标。
5. 下一步可练习的具体行为，取自各维度与下一等级相比仍缺少的可观察行为。

摘要不使用“合格”“通过”“达标”“优秀”等分类词。

S1a判为0级或1级时，摘要单列“本次通话未完成基础风险筛查”。这是行为是否发生的事实判定，不依赖岗位标准设定；但不计入非补偿性底线事件。底线事件记录明确的伤害性作为，未完成筛查属于不作为，两者分别记录。

每个维度展示：

- 当前等级及完整等级描述。
- 在本次通话中观察到的主要职业表现。
- 支持结论的原始对话和工作记录证据。
- 表现中的限制、矛盾和未观察部分。
- 与下一等级相比仍缺少的可观察行为。

报告必须醒目标注：

> 本结果由大模型依据模拟通话、语音过程和工作记录生成。使用结论前必须核对原始对话与工作记录，不得将模型概括替代原始证据。

报告不展示含义不清的“一致性百分比”，也不自动生成笼统的“建议人工复核”。如果存在材料冲突，应具体列出冲突的原话、记录字段和判断影响。

## 十、维度独立性检查

| 容易混淆的维度 | 划分标准 |
|---|---|
| C1关系维护与C2情绪理解 | C1看如何对待来电者；C2看是否准确理解其体验 |
| C2情绪理解与C5支持介入 | C2看理解和核对；C5看在理解基础上做了什么 |
| C3工作焦点与C4专业判断 | C3回答本次主要处理什么；C4回答如何理解问题及为什么这样排序 |
| C4专业判断与C9工作记录 | C4评价判断质量；C9评价记录是否准确、可追溯和诚实 |
| C5支持介入与C7伦理边界 | C5评价行动是否适合且可行；C7评价行动是否在职责和伦理范围内 |
| C6通话进程与C8结束安排 | C6评价通话进行中的媒介和结构管理；C8只评价结束条件及收束质量 |
| C6普通情绪停顿与S3严重失序 | 一般节奏调整归C6；持续失控、长时无法交流等高难度情景归S3 |
| C7服务边界与S5依赖压力 | C7评价一般边界能力；S5只在反复来电或明显关系施压时启用 |
| S1a基础筛查与S1b完整研判 | S1a只判断是否以适当方式触及风险方向；S1b评价风险信息的覆盖、整合和紧迫性判断 |
| S1b风险研判与S2安全处置 | S1b回答风险是什么、紧迫到什么程度；S2回答确认风险后采取什么现实安全行动 |
| S1b风险研判与C9工作记录 | S1b评价研判是否有依据；C9只评价风险依据和限制是否被准确写入并可回溯 |
| S2安全处置与C5协同行动 | 普通支持和行动归C5；只有高危状态下以降低即时危险为目的的行动归S2 |
| S2安全处置与C9工作记录 | S2评价通话中实际协商和落实的安全行动；C9评价记录是否准确区分已完成与拟采取 |
| S3严重失序与S1b、S2风险模块 | S3评价恢复交流和稳定过程；失序中出现的风险研判及安全行动分别归S1b和S2 |
| S5依赖压力与C1、C7 | C1评价关系维护，C7评价一般边界；S5只评价反复来电和依赖压力下如何同时维持关系与边界 |
| S6攻击骚扰与S1a、S1b | S6只评价攻击或骚扰行为的处理；同一通话中的风险筛查和研判分别归S1a、S1b |
| S7第三方来电与C7 | S7评价未在场者信息的证据限制和第三方可采取行动；C7评价一般隐私与服务范围 |
| S8特殊保护与C7、S2 | S8评价未成年人或受侵害情境中的特殊责任；一般伦理归C7，即时危险处置归S2 |
